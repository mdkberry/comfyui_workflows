**MBEDIT-v2v_LTX23_Upscaler-w-SingleSampler**
	- Messy wf as most stuff is disabled in it. but I've been testing this with upscaling Minimax H3 results to keep character consistency. This one actually almost works. As it stands on vrs3 it has become a resize to 3mp and low denoise through just one sampler with 4 steps starting at 0.64 sigmas which was the bite point for v2v work without losing consistency. I would push it to 4K if I could but it oomed on 8 second input above 2304 on the long edge. You may need to set your video to div by 32 both edges if it errors. I will supercede this with LTX 2.5 if it works. Testing today.
