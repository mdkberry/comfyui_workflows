*I like Bernini but it can't always do what Minimax can do. But I still find it good for short structural clips that I can then polish with a Minimax single sampler pass (5 seconds, 3 steps, denoise 0.3, after upscaling x2.5). Example, the ballerina stage hand off scene - Minimax couldnt get it right, Bernini did. So I used Bernini for structure, and Minimax to add final polish.*
